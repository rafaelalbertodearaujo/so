<p>Todos os codigos estão misturados, sem distinção entre as aulas, aproveite.</p>
<p>Utilize o comando abaixo para clonar a pasta:</p>
<hr>
<code>su -c "apt install git ; git clone https://github.com/rafaelalbertodearaujo/so"</code>
<hr>
<p>Após executar o comando, será necessário somente digitar a senha do root e confirmar com "y" no terminal, ele vai clonar o repositório com a pasta SO e os arquivos das aulas.</p>
